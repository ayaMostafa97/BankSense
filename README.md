# 🏦 BankSense — Banking Customer & Analytics Platform

An end-to-end banking analytics solution built to analyze customer transactions, liquidity trends, and key performance metrics using SQL, Power BI, and Python.

---

### 📌 Overview
**BankSense** provides comprehensive financial insights for banking data. The project covers data extraction, cleaning, SQL data warehousing, automated DAX measures, and interactive dashboards to enable data-driven decision-making.

---

### 🛠️ Tech Stack & Tools
* **Database & Warehousing:** SQL Server / PostgreSQL (Data Modeling, Queries, Views)
* **Business Intelligence:** Power BI (DAX Modeling, Power Query, Interactive Dashboards)
* **Data Processing & EDA:** Python (Pandas, NumPy, Jupyter Notebooks)
* **Documentation & Presentation:** Presentation Slide Deck & Project Reports

---

### 📂 Repository Structure

```text
BankSense/
│
├── data/                  # Raw and cleaned dataset files
│   ├── raw/               # Original unprocessed banking data
│   └── cleaned/           # Processed & structured data files
│
├── sql/                   # Database schemas, ETL scripts, & analytics queries
├── notebooks/             # Python Jupyter Notebooks for Data Cleaning & EDA
├── powerbi/               # Power BI Report (.pbix) & Dashboard files
├── documentation/         # Project documentation, data dictionaries, & reports
├── presentation/          # Project presentation slides
└── screenshots/           # Dashboard visual previews
📊 Key Dashboard Features & Metrics
Customer Segmentation & Demographics: In-depth customer behavior and account distribution.

Monthly Liquidity Trends: Time-series analysis of deposits, withdrawals, and cash flow.

KPIs & Strategic DAX Measures: Custom DAX measures for dynamic calculations and KPIs.

Interactive Slicers: Filtering by branch, product type, date range, and customer status.

🚀 How to Run the Project
Database Setup: Execute SQL scripts located in sql/ to build the database schema and populate tables.

Data Cleaning: Explore notebooks/ to view Python preprocessing steps.

Power BI Dashboard: Open .pbix file inside powerbi/ with Power BI Desktop to interact with the dashboard.
